[장마감 후 — 스토리텔링]
4. 코멘터리 & 투자자 일기 (시뮬 11명 + Q 정채원 + 메타 매니저) 생성 → daily_stories 테이블

## 리스크 관리

실전 자동 투자 전환을 대비한 안전장치. 현재 시뮬레이션 단계에서는 감지 + 기록 + 알림만 수행.

### 포지션 제한 (allocation 저장 시 자동 적용)
| 제한 | 기본값 | 예외 |
|------|--------|------|
| 단일 종목 최대 비중 | 30% | (N 전몰빵 정리됨) |
| 단일 섹터 최대 비중 | 50% | K 로로캅: 100% |
| 최소 현금 보유 | 5% | M 오판단: 0% |

### 리스크 이벤트 감지 (시뮬레이션 후 자동 실행)
| 이벤트 | 기준 | 심각도 |
|--------|------|--------|
| 일일 손실 | 전일 대비 -3% | critical |
| 누적 손실 | 시드 대비 -10% | critical |
| MDD | 최근 30일 고점 대비 -8% | critical |
| 연속 손실 | 5일 연속 하락 | warning |
| 종목 급변 | 개별 종목 ±10% | warning |

- 이벤트 발생 시 `risk_events` 테이블 기록 + 텔레그램 알림
- 설정: `config.risk_limits` (Supabase)에서 조정 가능

## 실전 투자 (메타 매니저)

A 강돌진 추종 모드(`follow_investor_id: "A"`)로 운영되는 실전 매매 시스템. 매일 A 투자자의 당일 allocation을 그대로 실전 target으로 복사하여 KIS API로 자동 체결한다.

- **증권사**: 한국투자증권 (KIS Developers REST API)
- **⚠️ KIS API 토큰**: 1일 1회 발급 원칙 — 유효기간 내 잦은 발급 시 이용 제한됨. Python `broker_client.py`만 발급 담당, Vercel은 Supabase에서 읽기만.
- **운영**: 자동 — A allocation 복사→텔레그램 알림→KIS API 자동 체결 (승인 절차 생략)
- **실행 시점**: 매일 시뮬레이션 직후 (`daily_pipeline_cron.sh` 끝에서 체이닝, 시가 근처 체결)
- **리밸런싱**: 매일 (A가 매일 리밸런싱) + 매일 긴급 손절/급락방어 체크
- **입출금 추적**: `--record-deposit` CLI로 기록, TWR 기반 수익률 계산 (입금 점프 영향 제거)
- **핵심 원칙**: 코스피 대비 초과 수익 (알파 양수 유지)

**보호 장치** (`config.risk_limits.meta_manager`):
| 장치 | 기준 | 비고 |
|------|------|------|
| 리밸런싱 주기 | **매일** | A가 매일 리밸런싱 (`rebalance_frequency: "daily"`) |
| 손절 | 레짐별 차등 (약세장 -7%, 중립장 -8%, 강세장 -10%) | 보유기간 무시, 즉시 매도 |
| 급락 방어 | +20% 도달 후 고점 대비 -15% 이탈 시 매도 | 수익 보호용 트레일링 |
| 레짐별 투자 한도 | **follow 모드에서 스킵** | A 원본 비중 그대로 재현 (`enforce_regime_limit` 스킵) |
| 최소 보유기간 | **1영업일** | A 매일 교체 대응 |
| 회전율 한도 | **총자산 95%** | A 고회전 대응 |
| 안정화 기간 | **종료 (~2026-04-10)** | 더 이상 적용 안 됨 |
| 종목 검증 | stock_universe 100종목만 허용 | 자동 제거 |

**안전 장치**: 일일 손실 -3% 자동 중단 / 누적 -10% 전량 청산 / 킬스위치 / 장 운영시간 외 주문 차단 (텔레그램 승인은 자동 모드로 즉시 체결)

**KOSPI 벤치마크**: yfinance(^KS11) 직접 조회로 누적수익률 계산. 매 실행 시 과거 데이터 자동 보정

|------|------|----------|

| **09:05** | 시뮬레이션 (뉴스 수집 → 11명 배분 → 시가 체결) → **시뮬레이션 직후 메타 매니저 체이닝** | Claude CLI |

- **분석** (`/analysis`): 전략 스코어카드(6개 카테고리 종합 평가·실전 추천 뱃지·백테스트 괴리율), 성과 지표(샤프비율·MDD·변동성·알파·승률), 국면별 성과(시장 레짐 타임라인·국면별 수익률·최적 조합), 수익률 상관관계 히트맵, 포지션 겹침률, 종목 인기도, 성과 기여도 분석. 각 섹션에 데이터 기반 전문가 인사이트 자동 생성
- **대결** (`/versus`): 추천 대결, 자유 선택, 주간 MVP/꼴찌, 연승 기록
- **대결 상세** (`/versus/[matchup]`): 1:1 자산 비교, 일별 수익률 차이, 포지션 비교
- **리그** (`/league`): 월간 시즌제 승점 순위(1위=15점~15위=1점), 누적 승점 추이 차트, 시즌 아카이브(클릭 시 과거 시즌 전체 순위표+승점 차트 표시)
- **백테스트** (`/backtest`): 과거 데이터 기반 전략 검증 결과 — 1개월/3개월/6개월/9개월/1년 기간 탭, 자산 추이 차트, 성과 순위표(샤프/MDD/변동성/승률 툴팁), 레이더 차트
- **뉴스 아카이브** (`/news`): 날짜별 뉴스 카드, 섹터별 아이콘
- **이야기 아카이브** (`/stories`): 과거 데일리 코멘터리 & 투자자 일기 (캘린더 탐색)
